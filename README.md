# Yasir Freelancer Portfolio

A responsive static portfolio website designed for GitHub Pages.

## Files
- `index.html` - website structure and content
- `style.css` - responsive styling
- `script.js` - mobile navigation
- `images/` - place project screenshots here

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your real email.
2. Replace `YOURNUMBER` in the WhatsApp link with your number including country code.
3. Replace the three project placeholders with your real projects and links.
4. Replace the `Y` placeholder with your profile photo if desired.
